# Recruitzaa - Project Deliverables & Proposal

## 1. Project Overview
The objective of this project is to develop **Recruitzaa** (recruitzaa.com) into a comprehensive EdTech-style recruiting, consulting, and employment outsourcing platform. The system will bridge the gap between recruiters and job seekers by providing an advanced, AI-powered matching and management ecosystem.

## 2. Scope of Deliverables
The development team will deliver the following core components:
1. **Responsive Web Application:** Built using React.js, integrated with a robust **Python backend**.
2. **Android Mobile Application:** Native or cross-platform Android app mimicking core web functionalities.
3. **iOS Application:** *(Note: Not included in the current scope/document. To be planned for future phases).*

---

## 3. Feature Breakdown

### 3.1 Web Platform: Job Seeker Portal
*   **Authentication & Onboarding:** Secure profile creation, registration, and login module.
*   **Job Board & Discovery:** 
    *   Display of comprehensive job listings.
    *   Job Search & Filter Engine with explicit navigation.
    *   One-click job application routing.
*   **Automated Job Scraping Engine:** A Python-based backend system designed to scrape daily job updates from different external target websites, storing and standardizing these job postings in our database to provide continuous opportunities to users.
*   **Resume Engine & Builder:** Users can input their details, and the platform will generate standard, professional resumes using **10 pre-designed, industry-standard templates**.
*   **AI Career Copilot Hub (Ask AI):** Integrated AI assistant to help candidates with ATS keyword match analysis, resume optimization, and career queries.
*   **AI Mock Interviews:** Interactive web module allowing candidates to practice interviews with AI in real-time and receive constructive feedback.
*   **Candidate Workspace Dashboard:** A dedicated portal to track application statuses, skill demand, and pipeline KPIs.

### 3.2 Web Platform: Recruiter / Employer Portal
*   **Employer Authentication:** Secure corporate registration and brand trust onboarding.
*   **Job Posting & Management:** Tools to create, edit, and publish job listings.
*   **Application Pipeline Board (Kanban):** Visual 5-stage workflow management (Saved → Applied → Screening → Interview → Offer) to track candidate progress.
*   **Candidate Search & AI Matching:** Ability to search the talent pool with AI-driven match badges to find the best fit.

### 3.3 Android Application Modules
*   **Profile Creation & Management:** Seamless mobile onboarding.
*   **Mobile Resume Generation:** Access to the resume builder and templates on the go.
*   **Ask AI:** Mobile integration of the AI career assistant.
*   **AI Mock Interviews:** Mobile-friendly interactive module for AI interview practice.

## 5. Important Notes & Legal Terms

To ensure a smooth delivery and clear boundaries of responsibility, the following terms apply to this agreement:

1. **Third-Party & Infrastructure Costs:**
    *   **Hosting & Server Charges:** All cloud infrastructure, server hosting, and database costs must be borne entirely by the Client.
    *   **AI & API Costs:** Any usage charges related to third-party APIs (e.g., OpenAI, Anthropic, cloud scrapers, etc.) are the sole responsibility of the Client. The development fee covers integration only.
2. **Design Freeze:**
    *   Once the UI/UX mockups and prototypes are approved by the Client, a **Design Freeze** goes into effect. Any subsequent structural or design changes will be subject to additional billing as a change request.
3. **Maintenance & Support:**
    *   Post-deployment, we will provide a **1-month grace period** for bug fixes related to the delivered code.
    *   This includes up to **10 minor maintenance/support requests for free**.
    *   Any major feature additions, extensive modifications, or maintenance beyond this quota will require a separate Maintenance Service Level Agreement (SLA).
4. **Ownership:** 
    *   Upon final payment, full ownership of the custom-written source code transfers to the Client.
