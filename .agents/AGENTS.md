# Workspace Rules for Recruitzaa-FE

## File & Git Hygiene Rules

- **Audit & Status Reports**: Any generated documentation reports (such as `*_AUDIT.md`, `*_FIX_STATUS.md`, `*_READINESS.md`, `PRODUCTION_READINESS.md`, `*_audit_report.md`, `implementation_plan*`, `*_proposal.md`) must NOT be committed to git.
- **Gitignore Maintenance**: If creating new local audit, analysis, status tracking, or report markdown files, verify they match existing ignore patterns in `.gitignore` or add them to `.gitignore` immediately upon creation.
